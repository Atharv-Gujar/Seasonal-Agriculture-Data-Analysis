This project analyzes a seasonal agriculture dataset covering 4,000 farm records across three growing seasons — Kharif, Rabi, and Zaid — to uncover how agricultural performance shifts with the seasons.

It Handle missing values, validate cost/revenue consistency, and engineer per-hectare metrics.

Compares productivity, economic, resource-efficiency and risk metrics across Kharif, Rabi, and Zaid.

Links environmental drivers (rainfall, temperature, disease risk) to performance differences using correlation analysis.
